⚡ Voltra MD REST API Reference

Integrate WhatsApp pairing, channel auto-reactions, poll voting, and session settings directly into your applications.

POST /api/v1/pair/code

Request a WhatsApp 8-character pairing code for device connection.

curl -X POST https://your-domain.com/api/v1/pair/code \ -H "Content-Type: application/json" \ -d '{"phone": "263786624966"}'
POST /api/v1/services/chreact

React to a WhatsApp channel post across all active connected sessions.

curl -X POST https://your-domain.com/api/v1/services/chreact \ -H "Content-Type: application/json" \ -d '{"url": "https://whatsapp.com/channel/0029VaXXXX/101", "emoji": "🔥"}'
POST /api/v1/services/pollvt

Submit poll votes on a WhatsApp channel poll post.

curl -X POST https://your-domain.com/api/v1/services/pollvt \ -H "Content-Type: application/json" \ -d '{"url": "https://whatsapp.com/channel/0029Vb8VyAo/130", "option": "Option 1"}'
POST /api/v1/settings/mode

Update bot operating mode requiring phone number & session PIN.

curl -X POST "https://your-domain.com/api/v1/settings/mode?session=263786624966&pin=12345678" \ -H "Content-Type: application/json" \ -d '{"mode": "public"}'
