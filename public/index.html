Complete REST API Documentation

Integrate pairing, QR codes, channel services, per-session settings, and admin APIs.

POST /api/v1/pair/code

Request an 8-character pairing code for device linking.

curl -X POST https://your-domain.com/api/v1/pair/code \ -H "Content-Type: application/json" \ -d '{"phone": "263786624966"}'
POST / GET /api/v1/pair/qrcode

Initialize QR pairing session and retrieve QR code string.

curl -X POST https://your-domain.com/api/v1/pair/qrcode \ -H "Content-Type: application/json" \ -d '{"phone": "263786624966"}'
POST / GET /api/v1/settings

Query or update all per-session settings (`botName`, `prefix`, `mode`, `antiCall`) in one unified call.

curl -X POST "https://your-domain.com/api/v1/settings?session=263786624966&pin=12345678" \ -H "Content-Type: application/json" \ -d '{"botName": "Voltra MD", "prefix": ".,#,$,%", "mode": "public", "antiCall": "on"}'
POST /api/v1/services/chreact

Broadcast post reactions across connected sessions.

curl -X POST https://your-domain.com/api/v1/services/chreact \ -H "Content-Type: application/json" \ -d '{"url": "https://whatsapp.com/channel/0029VaXXXX/101", "emoji": "🔥"}'
